# Εισαγωγή στην Ψηφιακή Ερευνητική Εμπειρογνωμοσύνη

> 🇬🇷 Ελληνική έκδοση του [Lab 01 — Introduction to Digital Forensics](../../Lab%2001/README.md)

> **Σημείωση:** Ο όρος **digital forensics** (ψηφιακή ερευνητική εμπειρογνωμοσύνη) αναφέρεται στην επιστημονική ανάκτηση, ανάλυση και παρουσίαση ψηφιακών στοιχεία ενόψει μιας νομικής διαδικασίας. Η περιγραφή του Ken Zatyko τονίζει ότι η διαδικασία αυτή απαιτεί νόμιμη εξουσιοδότηση αναζήτησης (search authority), **αλυσίδα διατήρησης** (chain of custody, δηλαδή καταγραφή του ποιος είχε στα χέρια του το στοιχείο και πότε), μαθηματική επιβεβαίωση (επιβεβαίωση μέσω hash), χρήση εργαλείων που έχουν εγκριθεί, επαναληψιμότητα, αναφορά ευρημάτων και τυχόν εμφάνιση ως εμπειρογνώμονας.

Απλά μιλώντας, η ψηφιακή ερευνητική εμπειρογνωμοσύνη είναι μια διαδικασία χρήσης της τεχνολογίας για τη συλλογή στοιχείων, την έρευνά τους και την παρουσίαση των ευρημάτων σε μια νομική υπόθεση. Μπορεί να περιλαμβάνει την εξέταση δραστηριότητας δικτύου, αρχείων καταγραφής εισόδου (access logs), ιστορικού αναζητήσεων, καθώς και ψηφικών μέσων αποθήκευσης όπως σκληροί δίσκοι και κινητές συσκευές, μαζί με την ανάλυση των δεδομένων αυτών για την εντοπισμό στοιχείων ποινικής δραστηριότητας ή άλλης παράνομης ενέργειας.

> **Γιατί μελετάμε αυτό;** Στην πραγματική ζωή, κάθε ενέργεια που εκτελεί ένας χρήστης ή ένα πρόγραμμα αφήνει ίχνη στο σύστημα. Τα **artifacts** (τεκμήρια ή «ψηφιακά ίχνη») είναι ακριβώς αυτά τα ίχνη: αρχεία, καταχωρήσεις registry, εγγραφές καταγραφής, μεταδεδομένα κ.ά. που παράγονται αυτόματα καθώς το σύστημα λειτουργεί. Τα artifacts υπάρχουν επειδή τα λειτουργικά συστήματα και οι εφαρμογές χρειάζονται αυτά τα δεδομένα για να δουλεύουν σωστά — και εμείς, ως ερευνητές, εκμεταλλευόμαστε αυτήν την ανάγκη για να ξαναχτίσουμε τι έγινε.

# Μερικοί τομείς εφαρμογής

**Έρευνα κυβερνοεπιθέσεων** — Σε περίπτωση παραβίασης ασφαλείας (security breach) ή κυβερνοεπίθεσης, η ψηφιακή ερευνητική εμπειρογνωμοσύνη μπορεί να χρησιμοποιηθεί για τον καθορισμό της έκτας, καθώς και της πηγής της επίθεσης. Αυτές οι πληροφορίες μπορεί στη συνέχεια να χρησιμοποιηθούν για τη βελτίωση των αμυντικών μέτρων του οργανισμού έναντι μελλοντικών επιθέσεων.

**Ανίχνευση απειλών και ανταπόκριση** — Μπορεί να είναι ιδιαίτερα χρήσιμο για την ενεργητική (proactive) εντοπισμό και μείωση απειλών ασφαλείας, πριν αυτές προκαλέσουν ζημιά.

**Ανάκτηση δεδομένων** — Η ψηφιακή ερευνητική εμπειρογνωμοσύνη μπορεί επίσης να χρησιμοποιηθεί για την ανάκτηση δεδομένων που μπορεί να κλάπηκαν ή να διαγράφηκαν κατά τη διάρκεια μιας επίθεσης.

**Ποινικές έρευνες** — Τα στοιχεία που συλλέγονται μπορούν να χρησιμοποιηθούν για την ταυτοποίηση υπόπτων, την απόδειξη κίνητρου και τη σύνδεση υπόπτων με συγκεκριμένες πράξεις.

Ο κοινός στόχος περιλαμβάνει τη συλλογή στοιχείων που μπορούν να χρησιμοποιηθούν για τη δίωξη υπόπτων σε δικαστήριο.

> **Συμβουλή:** Παρότι οι τέσσερις παραπάνω περιπτώσεις μοιάζουν διαφορετικές, μοιράζονται την ίδια λογική: **συλλογή → ανάλυση → αναφορά**. Η διαφορά βρίσκεται στο τι ψάχνουμε και στο ποιες αποδείξεις είναι αποδεκτές νομικά.

Το 2004, ενοχλημένος από την απουσία αναφορών στο πρόσωπό του από τον Τύπο, ξεκίνησε ξανά να στέλνει υλικό (σταυρόλεξα, κούκλες διαμορφωμένες όπως οι σκηνές των εγκλημάτων του και αποσπάσματα της αυτοβιογραφίας του).

# Βασικές εντολές γραμμής εντολών Linux

Αυτή η ενότητα λειτουργεί ως εισαγωγή στα εργαλεία γραμμής εντολών (command line) του Linux, τα οποία είναι απαραίτητα για την ψηφιακή ερευνητική εμπειρογνωμοσύνη.

Υπάρχουν πολλές εντολές Linux που μπορεί να αποδειχθούν χρήσιμες στην ερευνητική εμπειρογνωμοσύνη, όμως μερικές από τις πιο ουσιώδεις είναι:

> **Συμβουλή:** Πριν ξεκινήσεις τις ασκήσεις, άνοιξε μια τερματική Linux (π.χ. σε Kali Linux) και δοκίμασε κάθε εντολή όπως περιγράφεται. Η εμπειρία από την άμεση εκτέλεση κατανοείται πολύ καλύτερα από την απλή ανάγνωση.

## `ls` — χρησιμοποείται για την εμφάνιση των αρχείων και καταλόγων ενός καταλόγου

Η εντολή ls σάς επιτρέπει να δείτε μια λίστα με όλα τα αρχεία και τους φακέλους σε έναν συγκεκριμένο φάκελο

```
$ ls
Desktop  Documents  Downloads  Music  Pictures  Public  Videos
```

> **Συμβουλή:** Το `ls` δέχεται πολλά επιπλέον επιλογές, όπως το `ls -la` για λεπτομερή λίστα (including hidden files) και `ls -lt` για ταξινόμηση κατά χρόνο τροποποίησης — ιδιαίτερα χρήσιμο όταν ψάχνουμε πρόσφατα δημιουργημένα αρχεία.

## `cd` — χρησιμοποείται για την αλλαγή του τρέχοντος καταλόγου εργασίας

Η εντολή cd σάς επιτρέπει να αλλάξετε τον φάκελο στον οποίο εργάζεστε αυτή τη στιγμή.

```
$ cd Desktop/
```

## `cat` — χρησιμοποείται για την εμφάνιση των περιεχομένων ενός αρχείου

Η εντολή `cat` (συντομογραφία του "concatenate", δηλαδή «σύνδεση») σάς επιτρέπει να εκτυπώσετε τα περιεχόμενα ενός αρχείου.

```
$ cat file.txt 
Hello World!
```

> **Συμβουλή:** Προσοχή με το `cat` σε πολύ μεγάλα αρχεία: θα «σπάσει» την έξοδο της οθόνης. Για μεγάλα αρχεία προτιμήστε `less`, `head` ή `tail`.

## `strings` — χρησιμοποείται για την εμφάνιση εκτυπώσιμων συμβολοσειρών σε ένα αρχείο

Η εντολή `strings` σάς επιτρέπει να δείτε συμβολοσειρές κατανοητές από τον άνθρωπο μέσα σε ένα αρχείο, κάτι που βοηθά στον εντοπισμό τυχόν ύποπτων συμβολοσειρών. Στην πράξη, αυτό σημαίνει ότι μπορείτε να «δείτε» κείμενο ακόμη και μέσα σε εκτελέσιμα (binaries) ή σε αρχεία όπου το κείμενο δεν είναι εμφανές — π.χ. URLs, διευθύνσεις e-mail, μηνύματα σφαλμάτων ή ακόμη και κωδικούς που έχουν «σκορπιστεί» στον κώδικα.

```
$ strings file.txt 
Hello World!
```

```
$ strings /bin/bash
/lib64/ld-linux-x86-64.so.2
 $DJ
CDDB
E`% 
`0 	
"BB1
B8: 
0D@kB
) 9E4
NR l
 "?$aD
!A8H
h% H0A
Hap5
($B 
d> 7
<SNIP>
```

> **Προσοχή:** Το `strings` εξάγει ό,τι μοιάζει με κείμενο, οπότε θα βλέπετε συχνά και «θόρυβο» — τυχαίες ακολουθίες χαρακτήρων που δεν έχουν πραγματική σημασία. Μην υποθέτετε ότι κάθε εκτυπώσιμη συμβολοσειρά είναι σημαντική.

## `grep` — χρησιμοποείται για την αναζήτηση μιας συγκεκριμένης συμβολοσειράς ή ενός μοτίβου σε ένα ή περισσότερα αρχεία

Η εντολή `grep` είναι εξαιρετικά χρήσιμη για την αναζήτηση συμβολοσειρών σε μεγάλα αρχεία, όπως τα αρχεία καταγραφής (log files). Μπορεί να επιταχύνει δραστικά τις έρευνες επιτρέποντάς σας να αναζητήσετε μοτίβα όπως διευθύνσεις URL, διευθύνσεις E-mail, MD5 hashes και άλλα.

```
$ grep "Hello" file.txt 
Hello World!
```

> **Συμβουλή:** Το `grep` γίνεται ακόμη ισχυρότερο με επιλογές όπως `-i` (αναζήτηση χωρίς διακριτικότητα πεζών/κεφαλαίων), `-r` (αναδρομική αναζήτηση σε φακέλους) και `-n` (εμφάνιση των αριθμών γραμμής). Για παράδειγμα, `grep -ri "error" /var/log` ψάχνει το "error" σε όλα τα αρχεία του καταλόγου, ανεξαρτήτως πεζών/κεφαλαίων.

## `find` — χρησιμοποείται για την αναζήτηση αρχείων και καταλόγων

Η εντολή `find` μπορεί να χρησιμοποιηθεί για τον εντοπισμό διαφόρων τύπων αρχείων, καταλόγων, αρχείων με συγκεκριμένα δικαιώματα (permissions), πρόσφατα τροποποιημένων αρχείων κ.ά.

```
$ find . -type d
.
./Music
./Public
./Downloads
./Desktop
./.config
./.config/autostart
./.config/xfce4
./.config/xfce4/panel
./.config/cherrytree
./.config/powershell
./Pictures
./Documents
./.java
./.java/.userPrefs
./.java/.userPrefs/burp
./Videos
```

Προσέξτε πώς η παραπάνω έξοδος επιστρέφει λίγο περισσότερους καταλόγους από την εντολή `ls`.

> **Γιατί μετράει στην πράξη:** Ο εντοπισμός πρόσφατα τροποποιημένων αρχείων είναι μία από τις πιο συχνές ερευνητικές τεχνικές: όταν ένας εισβολέας ανεβάζει εργαλεία ή καταστρέφει δεδομένα, τα αρχεία που δημιουργεί ή αλλάζει ξεχωρίζουν από τα υπόλοιπα. Το `find` είναι ακριβώς το εργαλείο για αυτή τη δουλειά.

## `md5sum`, `sha1sum` — χρησιμοποούνται για τον υπολογισμό των MD5 και SHA1 hashes ενός αρχείου

Και οι δύο εντολές λαμβάνουν μια είσοδο και παράγουν μια συμβολοσειρά σταθερού μήκους, γνωστή και ως hash ή checksum (σύνοψη ελέγχου). Αν τα περιεχόμενα του αρχείου αλλάξουν, ακόμη και ελάχιστα, το hash του θα είναι διαφορετικό. Αυτό μπορεί να είναι χρήσιμο για τον εντοπισμό του αν ένα αρχείο έχει τροποποιηθεί ή παραπειραφθεί.

> **Θεωρητικό υπόβαθρο:** Το hash είναι μονοκατευθυντική συνάρτηση (one-way function): είναι εύκολο να υπολογιστεί, αλλά εξίσου αδύνατο να αντιστραφεί για να αποκτηθούν τα αρχικά δεδομένα. Για αυτό, στην ερευνητική εμπειρογνωμοσύνη τα hash λειτουργούν ως «δαχτυλίδια ταυτότητας» ενός αρχείου: προσφέρουν απόδειξη ότι ένα αρχείο δεν έχει αλλάξει, χωρίς να αποκαλύπτουν το περιεχόμενό του. Σημείωση: η MD5 και η SHA1 θεωρούνται σήμερα κρυπτογραφικά αδύναμες για σκοπούς ασφαλείας (υπάρχουν γνωστές συγκρούσεις hash), αλλά παραμένουν ιδιαίτερα δημοφιλείς στην ερευνητική εμπειρογνωμοσύνη για γρήγορη ταυτοποίηση αρχείων.

```
$ md5sum file.txt 
8ddd8be4b179a529afa5f2ffae4b9858  file.txt
```

```
$ sha1sum file.txt 
a0b65939670bc2c010f4d5d6a0b3e4e4590fb92b  file.txt
```

## `netstat` — χρησιμοποείται για την εμφάνιση πληροφοριών σχετικά με τις συνδέσεις δικτύου σε ένα σύστημα

Αυτό το εργαλείο παρέχει χρήσιμες πληροφορίες σχετικά με τις ενεργές συνδέσεις σε ένα σύστημα. Οι πληροφορίες που εμφανίζονται από αυτό το εργαλείο περιλαμβάνουν τις τοπικές και απομακρυσμένες διευθύνσεις και θύρες των ενεργών συνδέσεων.

```
$ netstat
Active Internet connections (w/o servers)
Proto Recv-Q Send-Q Local Address           Foreign Address         State      
tcp        0      0 192.168.0.106:44300     239.237.117.34.bc:https ESTABLISHED
tcp        0      0 192.168.0.106:39884     93.184.220.29:http      ESTABLISHED
tcp        0      0 192.168.0.106:58308     ec2-52-39-122-167:https ESTABLISHED
tcp        0      0 192.168.0.106:56910     static-48-7-129-15:http ESTABLISHED
udp        0      0 192.168.0.106:bootpc    192.168.0.1:bootps      ESTABLISHED
```

> **Γιατί μετράει στην πράξη:** Σε μια έρευνα, οι ενεργές συνδέσεις μπορούν να αποκαλύψουν επικοινωνία με κακόβουλο διακομιστή (C2), προωθημένες θύρες (port forwarding) ή ασυνήθιστες εξόδους δεδομένων. Η στήλη «State» δείχνει τη φάση της σύνδεσης — π.χ. `ESTABLISHED` σημαίνει ότι η σύνδεση είναι ενεργή τώρα.

## `file` — χρησιμοποείται για τον καθορισμό του τύπου ενός αρχείου με βάση τα περιεχόμενά του

Η εντολή `file` μπορεί να χρησιμοποιηθεί για την ταυτοποίηση αρχείων όπως κείμενο, εικόνες, ήχος, βίντεο και εκτελέσιμα αρχεία. Μπορεί επίσης να χρησιμοποιηθεί για την ταυτοποίηση άγνωστων αρχείων που ενδέχεται να είναι κακόβουλα.

> **Προσοχή:** Η εντολή `file` βασίζεται στα λεγόμενα **magic bytes** (τα πρώτα byte ενός αρχείου που «δηλώνουν» τον τύπο του). Ένας κακόβουλος δράστης μπορεί να αλλάξει την επέκταση ενός αρχείου (π.χ. να ονομάσει ένα πρόγραμμα `image.jpg`) — αλλά τα magic bytes μένουν συνήθως αμετάβλητα, οπότε το `file` αποκαλύπτει τον πραγματικό τύπο.

```
$ file /etc/passwd
/etc/passwd: ASCII text
```

```
$ file image.png 
image.png: PNG image data, 562 x 424, 8-bit/color RGB, non-interlaced
```

## `xxd` — χρησιμοποείται για την εκτύπωση hex dump ενός δοσμένου αρχείου

Η εντολή `xxd` είναι χρήσιμη για την εκτύπωση hex dump (δεκαεξαδική απεικόνιση) ενός δοσμένου αρχείου ή της τυπικής εισόδου (standard input). Μπορεί επίσης να μετατρέψει ένα hex dump πίσω στην αρχική του δυαδική μορφή.

```
$ xxd image.jpg 
00000000: ffd8 ffe0 0010 4a46 4946 0001 0101 0048  ......JFIF.....H
00000010: 0048 0000 ffdb 0043 0005 0304 0404 0305  .H.....C........
00000020: 0404 0405 0505 0607 0c08 0707 0707 0f0b  ................
00000030: 0b09 0c11 0f12 1211 0f11 1113 161c 1713  ................
00000040: 141a 1511 1118 2118 1a1d 1d1f 1f1f 1317  ......!.........
00000050: 2224 221e 241c 1e1f 1eff db00 4301 0505  "$".$.......C...
```

> **Εξήγηση εγγράφου:** Στην αριστερή πλευρά βλέπουμε τη μετατόπιση (offset) σε δεκαεξαδική μορφή, στο κέντρο τα ίδια τα byte σε hex, και στα δεξιά την «αναγνώσιμη» εκδοχή τους. Η πρώτη γραμμή του παραδείγματος ξεκινά με `ffd8 ffe0`, που είναι τα magic bytes μιας εικόνας JPEG — δηλαδή το `xxd` μάς δείχνει αυτό που το `file` μας είπε μόνο με λόγια.

## `hexedit` — χρησιμοποείται για την επεξεργασία αρχείων σε δεκαεξαδική μορφή

Το εργαλείο `hexedit` σάς επιτρέπει να επεξεργαστείτε τα ακατέργαστα bytes ενός αρχείου με διαδραστικό τρόπο. Χρησιμοποιείται συχνά για την επισκευή αρχείων που έχουν καταστραφεί (corrupted).

```
$ hexedit image.jpg
```

![Έξοδος](images/hexedit_output.png)

> **Προσοχή:** Η επεξεργασία raw bytes είναι ισχυρή αλλά επικίνδυνη ενέργεια. Πάντα δουλεύετε πάνω σε **αντίγραφο** του αρχείου και κρατήστε πάντα το αρχικό αρχείο ως απόδειξη, διαφορετικά θα χάσετε την ακεραιότητα του στοιχείου.

## `ps` — χρησιμοποείται για την εμφάνιση των διεργασιών που εκτελούνται στο σύστημα

Η εντολή `ps` σάς επιτρέπει να δείτε μια λίστα με όλες τις διεργασίες (processes) που εκτελούνται αυτή τη στιγμή στον υπολογιστή σας. Οι πληροφορίες που παρέχει περιλαμβάνουν το αναγνωριστικό διεργασίας (PID), τον χρήστη, την κατάσταση και την εντολή που ξεκίνησε τη διεργασία.

```
$ ps                    
    PID TTY          TIME CMD
   1824 pts/0    00:00:09 zsh
   2879 pts/0    00:00:05 sublime_text
   2924 pts/0    00:00:00 plugin_host-3.3
   2927 pts/0    00:00:00 plugin_host-3.8
  22666 pts/0    00:00:00 ps
```

> **Γιατί μετράει στην πράξη:** Σε ένα σύστημα που έχει μολυνθεί, οι διεργασίες είναι από τα πιο άμεσα artifacts. Ένα κακόβουλο πρόγραμμα πρέπει να εκτελεστεί για να δράσει, οπότε το «ποιο τρέχει τώρα» (και με ποια εντολή) είναι συχνά το πρώτο ερώτημα ενός ερευνητή. Αν υποψιαστείτε κάτι περίεργο, συγκρίνετε τη λίστα διεργασιών με αυτή ενός καθαρού συστήματος.

# Άσκηση

Για αυτή την ενότητα, δώστε τις πλήρεις εντολές για όλες τις ασκήσεις όπου ζητείται η εντολή, και δώστε μια περιγραφική απάντηση όπου ζητείται εξήγηση. Μπορεί να υπάρχουν πολλές απαντήσεις/εντολές για αυτές τις ασκήσεις, οπότε μην διστάζετε να υποβάλετε την απάντηση με την οποία νιώθετε πιο σιγουροι.

> **Συμβουλή:** Πριν απαντήσετε, δοκιμάστε κάθε εντολή σε ένα πραγματικό τερματικό. Αν η έξοδος δεν ταιριάζει με αυτή που περιμένατε, αυτό συχνά σας διδάσκει περισσότερα από την ίδια την απάντηση.

## Ερωτήσεις

1. Αν θέλαμε να εμφανίσουμε όλα τα αρχεία `.txt` στον τρέχοντα κατάλογο, ποια εντολή θα χρησιμοποιούσαμε;
2. Ποια εντολή μπορούμε να χρησιμοποιήσουμε για να διαβάσουμε τα περιεχόμενα του αρχείου `/etc/passwd`;
3. Αν θέλαμε να αναζητήσουμε τη συμβολοσειρά `Error` σε όλα τα αρχεία του καταλόγου `/var/log`, ποια θα ήταν η εντολή μας;
4. Ποιες θα ήταν οι εντολές για τον υπολογισμό των MD5 και SHA1 hashes του αρχείου `/etc/passwd`;

6. Ποια εντολή μπορούμε να χρησιμοποιήσουμε για να εμφανίσουμε όλες τις εκτυπώσιμες συμβολοσειρές μήκους ≥ 8 στο αρχείο `/bin/bash`;
