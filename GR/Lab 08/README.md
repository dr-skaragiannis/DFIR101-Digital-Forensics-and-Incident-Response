# Ψηφιακή Εξεταστική Μνήμης (Memory Forensics)

> 🇬🇷 Ελληνική έκδοση του [Lab 08 — Memory Forensics](../../Lab%2008/README.md)

Η εξεταστική της μνήμης (memory forensics) είναι ένα κρίσιμο υποπεδίο του ψηφιακού εντοπισμού αδικημάτων, το οποίο περιλαμβάνει την απόκτηση και την ανάλυση της εύθραυστης μνήμης ενός υπολογιστή ή, με άλλα λόγια, της RAM του υπολογιστή. Οι πληροφορίες που αποθηκεύονται στη RAM ενός υπολογιστή μπορούν να προσφέρουν πολύτιμες πληροφορίες για την κατάσταση του συστήματος τη στιγμή της απόκτησης. Το αποκτημένο αρχείο μνήμης αναφέρεται συνήθως ως **memory dump** (αποτύπωμα μνήμης) και μπορεί να είναι ιδιαίτερα χρήσιμο για την ταυτοποίηση εκτελούμενων διεργασιών, διαπιστευτηρίων χρηστών (user credentials), δικτυακών συνδέσεων, κλειδιών μητρώου (registry keys), κλειδιών κρυπτογράφησης, ιστορικού περιήγησης browser, περιεχομένου προχείρου (clipboard) και άλλων πολύτιμων πληροφοριών.

> 📚 **Γιατί η μνήμη έχει τόσο μεγάλη σημασία;** Η RAM είναι **εύθραυστη μνήμη** (volatile): ό,τι βρίσκεται μέσα της σβήνει μόλις το σύστημα κλείσει ή επανεκκινηθεί. Αυτό σημαίνει δύο πράγματα: (1) ότι δεν αφήνει μόνιμα ίχνη στο δίσκο — πολλές επιθέσεις, ιδίως τα λεγόμενα **fileless malware**, εκτελούνται αποκλειστικά μέσα στη μνήμη και δεν αφήνουν μόνιμο αρχείο στο δίσκο — και (2) ότι, αν δεν προλάβει κάποιος να τη συλλέξει πριν το κλείσιμο, η απόδειξη χάνεται για πάντα. Γι' αυτό στην πραγματική έρευνα η συλλογή μνήμης είναι συχνά **το πρώτο πράγμα** που κάνει ο ερευνητής, πριν ακόμη και αποσυνδέσει το σύστημα από τροφοδοσία.

Σε αυτό το εργαστήριο, θα εξερευνήσουμε τα θεμέλια της εξεταστικής μνήμης, συμπεριλαμβανομένων τεχνικών και εργαλείων για τη συλλογή και ανάλυση memory dumps που υποστηρίζουν την ανταπόκριση σε περιστατικά (incident response), την ανάλυση malware και άλλες εξεταστικές έρευνες.

## Απόκτηση Memory Dumps

Η απόκτηση των αποδεικτικών στοιχείων είναι πάντα το αρχικό βήμα σε κάθε έρευνα ψηφιακού εντοπισμού αδικημάτων, και στην εξεταστική μνήμης αυτό σημαίνει την απόκτηση της εύθραυστης μνήμης ενός υπολογιστή. Υπάρχουν αρκετά εργαλεία που μπορούμε να χρησιμοποιήσουμε για την απόκτηση memory dumps σε ζωντανά μηχανήματα, ωστόσο τα πιο συνηθισμένα περιλαμβάνουν:

- DumpIt — ένα ελαφρύ εργαλείο γραμμής εντολών για Windows.
- FTK Imager — ένα δημοφιλές εργαλείο εξεταστικής εικόνων (image forensics).
- Redline — ένα εργαλείο ανάλυσης μνήμης που αναπτύχθηκε από τη FireEye.


> 💡 Για να αποκτήσουμε μια εικόνα μνήμης από offline συστήματα Windows, μπορούμε να την εξαγάγουμε από το `%SystemDrive%/hiberfil.sys`, το οποίο περιέχει μια συμπιεσμένη εικόνα μνήμης από την προηγούμενη εκκίνηση που κανονικά διατηρείται για να προσφέρει ταχύτερες εκκινήσεις του συστήματος.

> 📚 **Σημείωση για το hiberfil.sys:** Αυτό το αρχείο δεν είναι πλήρης αντιγραφή της μνήμης — είναι συμπιεσμένη και, ανάλογα με τις ρυθμίσεις εξοικονόμησης ενέργειας, μπορεί να μην περιέχει όλα τα δεδομένα. Παρ' όλα αυτά, είναι ένα εξαιρετικά χρήσιμο ευρήματα όταν δεν υπάρχει ζωντανή πρόσβαση στο μηχάνημα, αφού μας δίνει μια "φωτογραφία" της μνήμης τη στιγμή του τελευταίου hibernate.

Σε αυτό το εργαστήριο, θα χρησιμοποιήσουμε το DumpIt για να συλλέξουμε ένα αρχείο memory dump για ανάλυση, το οποίο μπορεί να ληφθεί από το [https://raw.githubusercontent.com/thimbleweed/All-In-USB/master/utilities/DumpIt/DumpIt.exe](https://raw.githubusercontent.com/thimbleweed/All-In-USB/master/utilities/DumpIt/DumpIt.exe).

> ⏱️ **Σημείωση:** Η απόκτηση ενός memory dump μπορεί να είναι διαδικασία που απαιτεί πολύ χρόνο, οπότε μπορείτε να χρησιμοποιήσετε το memory dump που είναι διαθέσιμο για λήψη από τον σύνδεσμο που παρέχεται στην επόμενη ενότητα.

> ⚠️ **Προσοχή:** Η συλλογή μνήμης από ζωντανό σύστημα αλλάζει ελάχιστα τη μνήμη εκείνη τη στιγμή (το ίδιο το εργαλείο καταναλώνει μνήμη), οπότε η εικόνα δεν είναι 100% ακριβής απεικόνιση της πριν κατάστασης. Επίση, είναι κρίσιμο να ληφθεί το dump **πριν** το κλείσιμο ή την επανεκκίνηση του συστήματος· μετά την επανεκκίνηση, η εύθραυστη μνήμη έχει χαθεί οριστικά.

Όταν έχετε κατεβάσει το εργαλείο, κάντε διπλό κλικ στο εκτελέσιμο αρχείο. Αυτό θα εκκινήσει ένα command prompt που θα σας ζητήσει να επιβεβαιώσετε τη σύλλημη μνήμης πληκτρολογώντας 'y' ή 'n'. Πληκτρολογήστε 'y' για να επιβεβαιώσετε, και το εργαλείο θα ξεκινήσει αμέσως τη διαδικασία συλλογής της μνήμης:

Ως αποτέλεσμα, το αρχείο memory dump θα αποθηκευτεί στον ίδιο κατάλογο από τον οποίο εκκινήθηκε το εργαλείο.

> 💡 Η επέκταση του αρχείου memory dump μπορεί να διαφέρει ανάλογα με το εργαλείο που χρησιμοποιήθηκε για τη δημιουργία του dump. Ορισμένες συνηθισμένες επεκτάσεις για memory dumps περιλαμβάνουν `.raw`, `.mem`, `.vmem` και `.bin`.

## Ανάλυση Memory Dumps

Η ανάλυση memory dumps μπορεί να παρέχει πολύτιμες πληροφορίες για την κατάσταση ενός συστήματος τη στιγμή της απόκτησης του memory dump, όπως εκτελούμενες διεργασίες, δικτυακές συνδέσεις, διαπιστευτήρια χρηστών, ιστορικό περιήγησης, κλειδιά κρυπτογράφησης και οτιδήποτε άλλο μπορεί να βρισκόταν στη μνήμη τη στιγμή της απόκτησης, συμπεριλαμβανομένων τυχόν ίχνων (artifacts) που μπορεί να άφησε κάποιο malware. Αυτό είναι ιδιαίτερα χρήσιμο στην περίπτωση fileless malware, τα οποία τείνουν να εγκαθίστανται μέσα στη μνήμη.

> 🔤 **Τι είναι fileless malware;** Κακόβουλα προγράμματα που δεν γράφουν (ή γράφουν ελάχιστα) αρχεία στο δίσκο· εκτελούνται αποκλειστικά μέσα στη RAM, συχνά μέσω συσκευών του συστήματος όπως PowerShell, WMI ή σενάρια σε γλώσσες σεναρίων. Επειδή «δεν υπάρχει αρχείο» να σαρώσει ένα αντιίο, η εξεταστική μνήμης είναι συχνά ο **μόνος** τρόπος να τα εντοπίσετε.

Παρουσιάζουμε το [Volatility](https://github.com/volatilityfoundation/volatility), το εργαλείο που θα χρησιμοποιήσουμε για την ανάλυση memory dumps. Είναι ένα απαραίτητο εργαλείο εξεταστικής μνήμης στο εξοπλισμό ψηφιακού εντοπισμού αδικημάτων, είναι ανοιχτού κώδικα, γραμμένο σε Python, αποτελεί δημοφιλή επιλογή για την ανάλυση memory dumps και χρησιμοποιείται ευρέως από εξεταστές.

> ⚙️ **Σημείωση:** Πριν προχωρήσουμε στην εγκατάσταση, βεβαιωθείτε ότι έχετε Python 2 εγκατεστημένο στο σύστημά σας.

> 📚 **Σημείωση ιστορικού:** Το εν λόγω εργαστήριο χρησιμοποιεί την έκδοση Volatility 2, η οποία γράφτηκε για Python 2 — μια γλώσσα που έχει καταστεί από την 1η Ιανουαρίου 2020. Η σύγχρονη συνέχεια του έργου είναι το [Volatility 3](https://github.com/volatilityfoundation/volatility3), που υποστηρίζει Python 3 και έχει ελαφρώς διαφορετική σύνταξη εντολών (π.χ. δεν χρησιμοποιεί την επιλογή `--profile`, αλλά εντοπίζει μόνο του το σύστημα). Η γνώση και των δύο εκδόσεων είναι χρήσιμη, γιατί σε πραγματικές έρευνες θα συναντήσετε και τις δύο.

Για να εγκαταστήσετε το Volatility, ανοίξτε ένα τερματικό και εκτελέστε τις ακόλουθες εντολές:

```
git clone https://github.com/volatilityfoundation/volatility.git && cd volatility
sudo python2 setup.py install
sudo pip2 install pycryptodome
```

Αυτές οι εντολές θα κάνουν clone το αποθετήριο του Volatility από το GitHub και θα εγκαταστήσουν το εργαλείο και τις εξαρτήσεις του.

Για να επιβεβαιώσετε ότι το Volatility έχει εγκατασταθεί σωστά, μπορείτε να εκτελέσετε την εντολή `python2 vol.py` στο τερματικό, η οποία πρέπει να παράξει έξοδο παρόμοια με την ακόλουθη:

> 💡 **Συμβουλή:** Αν αργότερα χρειαστείτε τα plugins που απέτυχαν (για παράδειγμα ανάλυση κλήσεων API για malware), τότε πρέπει πράγματι να εγκαταστήσετε το `distorm3` — αλλιώς εκείνα τα plugins θα αποτυγχάνουν να φορτωθούν.

Αφού έχουμε εγκαταστήσει το volatility, το επόμενο βήμα πρέπει να είναι να αποκτήσουμε ένα memory dump για ανάλυση. Μπορείτε είτε να χρησιμοποιήσετε το DumpIt ή το FTK Imager για να συλλέξετε ένα, είτε, αν προτιμάτε, να κατεβάσετε το dump που έχω ήδη αποκτήσει από το [https://drive.google.com/file/d/1Gwe4jbv5qXO5WXQ-2p4N24HP6thC7l4Z/view?usp=sharing](https://drive.google.com/file/d/1Gwe4jbv5qXO5WXQ-2p4N24HP6thC7l4Z/view?usp=sharing).

Για να δώσουμε το αρχείο memory dump ως είσοδο στο Volatility, μπορούμε να χρησιμοποιήσουμε την επιλογή `-f` (θυμηθείτε να δώσετε την πλήρη διαδρομή στο αρχείο dump αν δεν βρίσκεται στον τρέχοντα κατάλογο):

```
$ python2 vol.py -f /path/to/smaple.mem
```

### Απαρίθμηση Δικτυακών Συνδέσεων

Για να απαριθμήσουμε τις ενεργές δικτυακές συνδέσεις τη στιγμή της απόκτησης του memory dump, μπορούμε να χρησιμοποιήσουμε το plugin `netscan`:

```
$ python2 vol.py -f sample.mem --profile Win7SP1x64 netscan

### Απαρίθμηση Μεταβλητών Περιβάλλοντος

Αν θέλουμε να δούμε μια λίστα μεταβλητών περιβάλλοντος (environment variables) τη στιγμή που αποκτήθηκε το memory dump, μπορούμε να χρησιμοποιήσουμε το plugin `envars`. Αυτό μπορεί να βοηθήσει στην ταυτοποίηση τυχόν μεταβλητών περιβάλλοντος που ενδέχεται να έχουν οριστεί από malware:

### Άλλα Plugins

Επιπλέον των plugins που αναφέρθηκαν παραπάνω, το Volatility έχει μια ευρεία γκάμα άλλων plugins που μπορούν να χρησιμοποιηθούν για την ανάλυση memory dumps. Μπορείτε να απαριθμήσετε τα διαθέσιμα plugins χρησιμοποιώντας την επιλογή `-h`:

```
$ python2 vol.py -f sample.mem --profile Win7SP1x64 -h

Μπορείτε να εξερευνήσετε την πλήρη γκάμα των διαθέσιμων plugins και τις λειτουργίες τους στο wiki αναφοράς εντολών του Volatility, το οποίο είναι διαθέσιμο στο [https://github.com/volatilityfoundation/volatility/wiki/Command-Reference](https://github.com/volatilityfoundation/volatility/wiki/Command-Reference).

> 💡 **Συμβουλή:** Μερικά ιδιαίτερα χρήσιμα plugins για αρχάριους, εκτός από τα παραπάνω, είναι το `cmdline` (τι εντολές δόθηκαν σε κάθε διεργασία), το `clipboard` (περιεχόμενο προχείρου), το `cmdscan`/`consoles` (ιστορικό εντολών του command prompt) και το `dlllist` (βιβλιοθήκες που φορτώνονται από κάθε διεργασία). Ξεκινήστε πάντα από τις βασικές λίστες (`pslist`, `netscan`, `cmdline`) πριν προχωρήσετε σε πιο εξειδικευμένα plugins.

## Συμπέρασμα

Για να κλείσουμε, η εξεταστική μνήμης είναι μια ισχυρή τεχνική στον τομέα του ψηφιακού εντοπισμού αδικημάτων. Αναλύοντας ένα memory dump, μπορούμε να εξαγάγουμε πολύτιμες πληροφορίες όπως εκτελούμενες διεργασίες, δικτυακές συνδέσεις, μεταβλητές περιβάλλοντος και πολλά άλλα, τα οποία μπορούν να βοηθήσουν στον εντοπισμό της ρίζας του προβλήματος (root cause) ενός περιστατικού και να μας βοηθήσουν να διατηρήσουμε μια προληπτική προσέγγιση έναντι πιθανών περιστατικών ασφαλείας στο μέλλον.

Τέλος, ενώ έχουμε καλύψει μόνο τα βασικά, υπάρχουν πολλές άλλες μεθοδολογίες που δεν συζητήθηκαν σε αυτό το εργαστήριο, τις οποίες σας παρακαλώ να εξερευνήσετε μόνοι σας. Προτείνω ιδιαίτερα να δείτε το βιβλίο [The Art of Memory Forensics](https://www.amazon.com/Art-Memory-Forensics-Detecting-Malware/dp/1118825098) ως σημείο εκκίνησης. Επιπλέον, αν χρειάζεστε να εξασκήσετε τις δεξιότητές σας στην εξεταστική μνήμης, μπορείτε να δείτε το [MemLabs](https://github.com/stuxnet999/MemLabs), μια συλλογή εκπαιδευτικών εργαστηρίων σε στιλ CTF.

# Ασκήσεις

Εργάζεστε ως ανώτερος ερευνητής ψηφιακού εντοπισμού αδικημάτων για μια υπηρεσία πληροφοριών που ειδικεύεται στην έρευνα εγκληματιών του κυβερνοχώρου. Πρόσφατα, έκαναν σημαντική πρόοδο σε μια υπόθεση κατά μιας ομάδας ransomware διαβόητης και κατόρθωσαν να συλλάξουν αρκετά μέλη της ομάδας, συμπεριλαμβανομένου του αρχηγού της. Στη διάρκεια της σύλληψης, η ερευνητική ομάδα απέκτησε memory dumps από τον υπολογιστή καθενός από τα μέλη της συμμορίας.

Υπάρχει υποψία ότι ο αρχηγός χρησιμοποιούσε Windows 7 εκείνη την περίοδο και είχε κρύψει ορισμένες μυστικές πληροφορίες σχετικές με τις λειτουργίες της ομάδας στον υπολογιστή του. Ως ανώτερο στέλεχος της ερευνητικής ομάδας, η υπηρεσία πληροφοριών σας έχει εμπιστευτεί το memory dump του υπολογιστή του αρχηγού και σας έχει αναθέσει την εύρεση των μυστικών πληροφοριών, οι οποίες ενδέχεται να βρίσκονται στις ακόλουθες θέσεις:

- Μπορεί να έχουν αντιγραφεί στο πρόχειρο (clipboard).
- Μπορεί να έχουν αναζητηθεί στο Internet.
- Μπορεί να έχουν αποθηκευτεί σε μια μεταβλητή περιβάλλοντος (environment variable).
- Μπορεί να έχουν εκτελεστεί ως εντολή (command).
- Μπορεί να έχουν σχεδιαστεί με το MSPaint.

Οι μυστικές πληροφορίες που αναζητάτε έχουν τη μορφή μιας flag με μορφή `flag{xxxx}`, όπου το `xxxx` αντιπροσωπεύει ένα σύνολο αλφαριθμητικών χαρακτήρων που αποτελούν τη flag. Υπάρχουν συνολικά 5 flags που πρέπει να βρείτε. Καλή επιτυχία!

> 💡 **Συμβουλή προσέγγισης:** Αντιστοιχίστε κάθε από τις 5 υποθέσεις με το κατάλληλο plugin που δείξαμε παραπάνω (π.χ. πρόχειρο → `clipboard`, εντολές → `cmdline` ή `cmdscan`, μεταβλητές περιβάλλοντος → `envars`). Για την αναζήτηση στο Internet και το MSPaint, θα χρειαστείτε plugins που δεν δείξαμε στο συγκεκριμένο εργαστήριο — ρίξτε μια ματιά στην αναφορά εντολών του Volatility παραπάνω.
