# DFIR-101: Digital Forensics and Incident Response

This repository provides a structured, hands-on introduction to Digital Forensics and Incident Response (DFIR). The course covers the fundamental concepts, tools, and techniques used to investigate digital incidents, preserve and analyze digital evidence, and reconstruct events across common computing environments.

## Course Summary

This lab series takes learners from core forensic principles through practical exercises in artifact analysis, document examination and steganography, web attack forensics, network traffic analysis, disk imaging and examination, malware analysis, memory forensics, container forensics, and password cracking. Each lab includes educational material, example datasets, and guided exercises to reinforce investigative workflows and sound evidence-handling practices.
